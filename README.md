# 🍽️ FoodieReview — Share & Discover the Best Food Experiences

**Live Site:** [https://local-food-lovers-networ-7125e.web.app](https://local-food-lovers-networ-7125e.web.app)

## 📖 Overview
**FoodieReview** is a modern food review platform where users can explore, share, and manage restaurant reviews.  
The site features dynamic data fetching, secure authentication, responsive design, and seamless MongoDB integration.

---

## 🎯 Project Purpose

The goal of FoodieReview is to provide a clean, user-friendly platform where users can confidently explore food experiences, share honest opinions, and manage their favorite reviews in a secure and responsive environment.

---

## ✨ Key Features

- 🔥 **Dynamic Reviews:** All reviews are fetched from MongoDB with real-time updates.
- ⭐ **Top-Rated Reviews:** Homepage highlights the highest-rated food reviews.
- ✍️ **Review Management:** Logged-in users can add, edit, and delete their own reviews.
- ❤️ **Favorites System:** Users can save and manage favorite reviews.
- 🔍 **Server-Side Search:** Search food reviews by name using MongoDB `$regex`.
- 🔐 **Protected Routes:** Secure access to private pages using authentication guards.
- 📱 **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices.
- ⚠️ **Custom Error Handling:** User-friendly 404 error page for invalid routes. 

---

## 🧩 Technologies Used

**Frontend:** React, React Router, Tailwind CSS, DaisyUI, Axios, React Hot Toast, React Slick  
**Backend:** Node.js, Express.js, MongoDB  
**Authentication:** Firebase Authentication  
**Hosting:** Firebase / Vercel

## ⚙️ Environment Variables

Create a `.env` file in the root directory and add:

```env
VITE_API_BASE_URL=your_backend_url
VITE_FIREBASE_API_KEY=your_key
VITE_FIREBASE_AUTH_DOMAIN=your_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```
